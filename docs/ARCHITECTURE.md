# Architecture

The repository is organized into three major areas:

- `frontend/student_app`: Flutter Web student and faculty applications.
- `backend`: Dart Shelf HTTP API and database integration.
- `docs`: project and deployment documentation.

The code was reorganized without changing the existing API endpoints or the core application behavior. The moved student/faculty implementations remain intact inside their screen directories, while the top-level Dart entrypoints are thin wrappers.
